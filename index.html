⚡ Connect your AI

Paste your API key to start. This app has no backend of its own — it talks directly from your browser to the model provider.

🔒 How your key stays private
  • The key is saved only in this browser's local storage (or nowhere, if you uncheck “remember”).
  • It is never in the app's code, the GitHub repo, or the URL — sharing this app (e.g. via GitHub Pages) shares nothing.
  • The only request that carries the key goes straight to the model provider, over HTTPS.
  • Visitors of the shared app see this same empty setup screen — they cannot see your key.
